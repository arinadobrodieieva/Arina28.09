Розділ 1: Кольори в HTML та CSS

У веб-дизайні кольори можна задавати кількома основними способами за допомогою CSS:

1. Назви кольорів: безпосереднє використання слів, наприклад: red, blue, green.

2. HEX-коди: шістнадцяткові значення, які починаються з решітки. Наприклад, глибокий фіолетовий колір цієї сторінки — це код #6c5ce7.

3. Формат RGB / RGBA: задає змішування червоного, зеленого та синього каналів. Літера «A» відповідає за прозорість (від 0 до 1). Наприклад: rgba(108, 92, 231, 0.1).

Розділ 2: Що таке CSS та як він працює?

CSS (Cascading Style Sheets) — це каскадні таблиці стилів. Якщо HTML відповідає за каркас та текст сайту, то CSS перетворює його на красиву цукерку.

За допомогою CSS на цій сторінці було налаштовано:

  • Шрифти: прибрано стандартний Times New Roman та встановлено плавний Segoe UI.
  • Тіні: додано м'яку тінь box-shadow під кожним білим блоком для ефекту глибини.
  • Градієнт: шапка сайту розфарбована не одним кольором, а плавним переливом від фіолетового до бузкового.

✨ Поради для Хацько Євгенії: як зробити цей сайт ще більш привабливим

Євгеніє, щоб перетворити звичайну веб-сторінку на професійний, сучасний сайт, варто впровадити такі кроки:

  • Анімації при наведенні (Hover-ефекти): Можна додати плавне збільшення блоків або зміну кольору посилань, коли користувач наводить на них курсор миші (використовуючи CSS-властивість transition).
  • Кастомні шрифти: Замість системних шрифтів підключіть стильні безкоштовні шрифти через Google Fonts (наприклад, Montserrat для заголовків та Inter для звичайного тексту).
  • Якісна інфографіка та іконки: Замініть звичайні маркери списків на красиві іконки з бібліотеки FontAwesome або додайте легкі SVG-ілюстрації.
  • Темна тема (Dark Mode): Сучасний тренд — додавання перемикача між світлою та темною темами сайту. Це не тільки красиво, але й береже очі користувачів увечері.
  • Ефект Скломорфізму (Glassmorphism): Створення напівпрозорих задніх фонів із розмиттям за допомогою CSS-команди backdrop-filter: blur(), що імітує матове скло.
